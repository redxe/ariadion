# ariadion-simulator-numpy

Optional NumPy complex128 simulation kernels for the
[Ariadion](https://github.com/redxe/ariadion) quantum programming platform.

Provides a `NumpyStateVectorBackend` using NumPy complex128 arithmetic. Ariadion's
release validation compares its results with the reference simulator.

Install explicitly if you need the NumPy backend. Most users should start with
[`ariadion`](https://github.com/redxe/ariadion).

Requires NumPy >= 1.26.
