# theonoe

Inspection and debugging engine for the
[Ariadion](https://github.com/redxe/ariadion) quantum programming platform.

Provides trace inspection, structured debugger output, noise-impact reporting,
bare-reliability reporting, and protection-requirement analysis.

This is an internal inspection package. Most users should install
[`ariadion`](https://github.com/redxe/ariadion) instead.
