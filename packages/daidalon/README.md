# daidalon

Compiler and synthesis engine for the
[Ariadion](https://github.com/redxe/ariadion) quantum programming platform.

Translates Ariadion's logical quantum semantics to scheduled gate-level
intermediate representation for simulation.

This is an internal compiler package. Most users should install
[`ariadion`](https://github.com/redxe/ariadion) instead.
