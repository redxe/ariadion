# Naming system

The brand architecture intentionally uses one memorable master brand and only two mythology-derived subsystem names.

| Name | Role | Story |
|---|---|---|
| Ariadion | platform, language, SDK, Studio | Ariadne's thread: a navigable path through complexity |
| Daidalon | compiler and synthesis engine | Daedalus: constructing intricate mechanisms |
| Theonoe | debugger and inspection engine | prophetic insight into hidden state |

Most remaining products stay descriptive:

- Ariadion Studio
- Ariadion Runtime
- Ariadion Simulator
- Ariadion Link
- Ariadion Learn
- Ariadion Capsules

This keeps the mythology meaningful without forcing users to memorize a pantheon.
